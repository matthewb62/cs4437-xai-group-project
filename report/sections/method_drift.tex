We split the period from 8 November 2025 to 9 October 2026 into
consecutive 14-day windows (fortnights). Test windows
start on 28 February 2026, the first day of the shock, and eight baseline
windows run back from it. The model is never retrained, so any change comes from the data.

\textbf{Explanation drift.} For each window we compute TreeSHAP values
\cite{lundberg2020} for every hour and score each feature by its mean
absolute SHAP value over the window. The reference ranking comes from the
October 2025 validation month. We compare each window's ranking to the
reference with weighted Kendall's tau $\tau_w$ \cite{kendall1938,vigna2015}
(1: same order; 0: unrelated; $-1$: reversed), which weights each
feature pair by $w_{ij} = \frac{1}{r_i+1} + \frac{1}{r_j+1}$, where $r$
is a feature's rank (0 for the top), so pairs near the top of the
ranking count most. Weighting matters because the top four of twelve
features carry 79\% of October's SHAP mass. We also compare each window with the same fortnight a year earlier.

\textbf{Input drift.} We compute the PSI \cite{yurdakul2018} for each
non-calendar input, measuring how much the
spread of its values has shifted compared with the same 14 days one year
earlier (0 means no shift). We average these PSI values to
give one PSI per window, and also flag any single input at or above
0.25, a commonly used cut-off \cite{yurdakul2018}.

\textbf{Warning rule.} We treat the eight baseline windows as normal
behaviour. For each of $\tau_w$, MAE and PSI we take its mean and
standard deviation (SD) over these windows. A test window raises a
warning when it lies more than 2~SD from the mean in the worse
direction, which is lower for $\tau_w$ and higher for MAE and PSI. For
the blind model this puts the $\tau_w$ warning line at 0.71. Lead time
is the number of days between the first $\tau_w$ warning and the first
MAE warning. We also report a stricter variant that needs two
consecutive windows over the line.
