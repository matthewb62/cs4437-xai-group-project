SHAP assigns each feature a contribution to a single prediction, using
Shapley values from game theory \cite{lundberg2017}. Averaging the absolute
contributions over many predictions ranks the features globally. For tree
ensembles such as LightGBM \cite{ke2017}, TreeSHAP computes these values
exactly and fast enough to explain every hour of a long test period
\cite{lundberg2020}. We chose SHAP over permutation importance
\cite{breiman2001}, also covered in the module, because permutation
importance needs the true price, which a deployed model does not yet have.

Our setup follows Trebbien et al. \cite{trebbien2023}, who used
gradient-boosted trees and SHAP to explain German day-ahead prices. They
found load, wind and solar to be the main drivers, with fuel prices also
mattering. Their model analyses prices after the fact, so it uses observed
values and fuel prices, and is explained once over a fixed period.

Concept drift can affect the inputs, the link between inputs and target, or
both \cite{gama2014}. Many monitors watch only the inputs, and the
Population Stability Index (PSI), which compares an input's distribution now
with a reference distribution, is a common example from credit scoring
\cite{yurdakul2018}. A shift in the inputs does not always hurt the model's accuracy, however,
so such monitors can raise false alarms \cite{mougan2025}. Explanations
depend on both the data and the model. Dem\v{s}ar and Bosni\'{c}
\cite{demsar2018} detected drift in synthetic data streams by watching a
classifier's explanations change. Lundberg et al. \cite{lundberg2020} split
a hospital model's loss among its features over a simulated deployment,
which revealed errors that overall loss hid, but loss needs the true
outcome. Mougan et al. \cite{mougan2025} define \emph{explanation shift} as
a change in how predictions are explained on new data compared with training
data, and detect it with a classifier on SHAP values, which they find more
sensitive than checks on the inputs alone.

Unlike Trebbien et al., our main model never sees a fuel price, and we
follow its explanations through a real, dated shock rather than one fixed
period. Unlike Mougan et al., we use a directly readable rank measure, held
to the same warning rule as error and PSI so the three signals can be
compared by date.
